# CodeAlpha Email Extractor 📧

A simple Python automation tool that extracts email addresses from a text file and saves the extracted emails into a separate file.

## 📌 Features

* Reads text from an input file
* Detects email addresses using Regular Expressions
* Displays the extracted email addresses
* Saves extracted emails to `emails.txt`
* Simple and beginner-friendly Python automation project

## 🛠️ Technologies Used

* Python
* Regular Expressions (`re`)
* File Handling

## 📂 Project Structure

```text
CodeAlpha_Email_Extractor
│
├── email_extractor.py
├── input.txt
└── emails.txt
```

## ▶️ How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
python email_extractor.py
```

4. The program extracts the email addresses from `input.txt`.
5. The extracted emails are saved in `emails.txt`.

## 📊 Sample Output

```text
Found email addresses:
support@example.com
john.doe@gmail.com
admin@codealpha.com

📁 Email addresses saved to emails.txt
```
